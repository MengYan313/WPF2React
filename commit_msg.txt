W2MR 1.3: 统一技术栈版本并修复 MUI v5 API 兼容性

## 版本变更

### 主要版本调整
- **React**: 19.2.0 → 18.2.0
- **Material-UI (MUI)**: 7.3.7 → 5.18.0
- **Emotion**: 新增 11.11.x（MUI v5 的样式引擎）
- **TypeScript**: latest stable → 5.9.3

### 版本变更原因
1. **React 18.2.0**: 更稳定的 LTS 版本，与 MUI v5 完全兼容
2. **MUI 5.18.0**: 稳定版本，API 成熟，文档完善
3. **Emotion 11.11.x**: MUI v5 的默认样式引擎，必须明确版本
4. **TypeScript 5.9.3**: 固定版本确保类型检查一致性

## MUI API 变化（v7 → v5）

### 1. Grid 组件 API 变化
**v7 API（已弃用）:**
```tsx
<Grid container spacing={2}>
  <Grid size={{ xs: 12, md: 4 }}>  // v7 新 API
    <Item>Content</Item>
  </Grid>
</Grid>
```

**v5 API（当前使用）:**
```tsx
<Grid container spacing={2}>
  <Grid item xs={12} md={4}>  // v5 标准 API
    <Item>Content</Item>
  </Grid>
</Grid>
```

**关键变化:**
- v7 使用 `size` prop 控制列宽
- v5 使用 `item` prop + 断点属性（xs, sm, md, lg, xl）
- v5 必须显式使用 `item` prop 标识 Grid 项

### 2. Checkbox 组件 API 变化
**v7 API（已弃用）:**
```tsx
const label = { slotProps: { input: { 'aria-label': 'Checkbox demo' } } };
<Checkbox {...label} />
```

**v5 API（当前使用）:**
```tsx
const label = { inputProps: { 'aria-label': 'Checkbox demo' } };
<Checkbox {...label} />
```

**关键变化:**
- v7 使用 `slotProps` 统一管理所有插槽属性
- v5 使用组件特定的 props（如 `inputProps`）

### 3. Menu 组件 API 变化
**v7 API（已弃用）:**
```tsx
<Menu
  slotProps={{
    list: {
      'aria-labelledby': 'basic-button',
    },
  }}
>
```

**v5 API（当前使用）:**
```tsx
<Menu
  MenuListProps={{
    'aria-labelledby': 'basic-button',
  }}
>
```

**关键变化:**
- v7 使用 `slotProps` 统一管理子组件属性
- v5 使用特定的 props（如 `MenuListProps`）

### 4. SpeedDial 组件 API 变化
**v7 API（已弃用）:**
```tsx
<SpeedDialAction
  slotProps={{
    tooltip: {
      title: action.name,
    },
  }}
/>
```

**v5 API（当前使用）:**
```tsx
<SpeedDialAction
  tooltipTitle={action.name}
/>
```

**关键变化:**
- v7 使用 `slotProps` 传递 tooltip 属性
- v5 直接使用 `tooltipTitle` prop

1. **迁移输出**: 所有迁移生成的代码将使用 MUI v5 API
2. **组件选择**: MUI 组件选择逻辑将基于 v5 组件库

4. **类型检查**: TypeScript 5.9.3 确保类型安全

## 向后兼容性

⚠️ **注意**: 此版本变更不向后兼容。之前使用 MUI v7 API 生成的代码需要手动迁移到 v5 API。

主要迁移点：
- Grid: `size` → `item` + 断点属性
- Checkbox: `slotProps.input` → `inputProps`
- Menu: `slotProps.list` → `MenuListProps`
- SpeedDial: `slotProps.tooltip` → `tooltipTitle`
